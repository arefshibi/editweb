# دفتر یافته‌های امنیتی CarMaa — snapshot فعلی

این دفتر یافته‌های مشاهده‌شده در سورس و شرایط محیط را ثبت می‌کند؛ جایگزین گزارش تست نفوذ مستقل نیست. شدت زیر برآورد ریسک پروژه‌ای است، نه CVSS نهایی.

| ID | شدت | یافته | وضعیت/شاهد |
|---|---|---|---|
| CM-001 | High | OTP ثابت و مسیر ورود نمایشی در فرانت‌اند قبلی | کد ثابت حذف شده؛ تأیید OTP واقعی هنوز به کلید پیامک/staging نیاز دارد. |
| CM-002 | High | پنل مدیریت و تصمیم‌های role متکی به مرورگر در نسخهٔ قبلی | پنل جدید ابتدا session/role سرور را چک می‌کند؛ آزمون roleها با DB واقعی هنوز انجام نشده. |
| CM-003 | Critical | پرداخت نمایشی سمت کلاینت می‌توانست خدمت را فعال کند | موفقیت ساختگی حذف شده؛ تأیید نهایی provider sandbox/production هنوز تست نشده. |
| CM-004 | High | migration اولیه شامل COMMIT داخلی و می‌توانست پیش از ثبت schema version تراکنش را ببندد | BEGIN/COMMIT سطح فایل حذف شده؛ regression test جدید اضافه شده؛ migration روی PostgreSQL واقعی هنوز اجرا نشده. |
| CM-005 | High | در API mode ممکن بود تایمر moderation سمت کلاینت آگهی را خودکار منتشر کند | تایمر فقط در حالت غیر API اجازه دارد؛ تست regression اضافه شده. |
| CM-006 | Medium | DTO عمومی می‌توانست دلیل رد آگهی را انتخاب کند | دلیل رد فقط در `/listings/mine` انتخاب می‌شود؛ تست قرارداد سورس اضافه شده. |
| CM-007 | Medium | تصاویر با scheme ناامن یا HTTP نباید وارد DTO عمومی شوند | helper فرانت‌اند آن‌ها را رد می‌کند؛ تست runtime VM اضافه شده. |
| CM-008 | High | بعضی جریان‌ها هنوز localStorage و دادهٔ نمایشی دارند | باز؛ مانع انتشار. فهرست در `remediation-plan.md` آمده است. |
| CM-009 | Medium | bridge صفحهٔ آگهی فقط ۵۰ نتیجهٔ اول را sync می‌کند | باز؛ محدودیت عملکرد/کامل‌بودن داده، نه مجوز دورزدن. |
| CM-010 | High | dependency install/lockfile/SAST/DAST و runtime test در این محیط قابل اجرا نبود | آزمون‌نشده؛ نیازمند CI/staging با شبکه و سرویس‌های واقعی. |

## وضعیت آزمون‌ها
پس از اصلاحات فعلی، `npm test` شامل ۲۵ تست محلی است و همه pass شده‌اند. این تست‌ها ترکیبی از unit test و source-contract/static checks هستند؛ هیچ route زنده‌ای روی PostgreSQL/Redis اجرا نشده و هیچ حملهٔ شبکه‌ای انجام نشده است.
