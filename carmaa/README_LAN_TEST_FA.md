# راه‌اندازی تست محلی CarMaa روی ویندوز و گوشی

## فایل‌های افزوده‌شده
- `START_CARMA_LAN.ps1`: تولید خودکار رازهای محیطی در اجرای اول، شناسایی IP شبکه، اجرای Docker Compose، migration، ساخت کپی فرانت‌اند بدون پوشه backend و شروع وب‌سرور.
- `ENABLE_CARMA_FIREWALL.ps1`: قواعد فایروال فقط برای شبکه محلی و پروفایل Private؛ باید با Administrator اجرا شود.
- `STOP_CARMA_LAN.ps1`: توقف وب‌سرور و کانتینرها، بدون حذف دیتابیس.

## روش اجرا
1. Docker Desktop را نصب و باز کن (WSL 2 فعال باشد).
2. Python 3 را نصب کن و گزینه Add Python to PATH را فعال کن.
3. لپ‌تاپ را به Wi-Fi مطمئن وصل کن. برای گوشی و لپ‌تاپ از یک شبکه استفاده کن.
4. روی `START_CARMA_LAN.ps1` راست‌کلیک کن و Run with PowerShell را انتخاب کن. اگر سیاست اجرای اسکریپت مانع شد، PowerShell را در پوشه پروژه باز کن و فقط برای همان نشست اجرا کن: `Set-ExecutionPolicy -Scope Process Bypass` سپس `./START_CARMA_LAN.ps1`.
5. اگر گوشی وصل نشد، در شبکه خانگی/مطمئن، شبکه ویندوز را Private کن و `ENABLE_CARMA_FIREWALL.ps1` را با Run as Administrator اجرا کن.
6. آدرس Website که اسکریپت چاپ می‌کند را در گوشی باز کن. هر دو دستگاه باید به همان Wi-Fi وصل باشند.
7. برای توقف `STOP_CARMA_LAN.ps1` را اجرا کن.

## نکات
- فایل `backend/.env` حاوی رمزهاست؛ آن را ارسال نکن و در پوشه فرانت‌اند قرار نده.
- PostgreSQL و Redis هیچ پورتی روی میزبان منتشر نمی‌کنند. فقط API روی IP شبکه لپ‌تاپ و پورت 3000 منتشر می‌شود.
- این تنظیمات برای تست LAN است، نه انتشار عمومی اینترنت. Port forwarding مودم را فعال نکن.
- برای تست محلی با `NODE_ENV=development`، مقدار `DEV_OTP_CODE=123456` در `backend/.env` فعال است و پیامک ارسال نمی‌شود؛ پس از درخواست کد، `123456` را وارد کن. این کد ثابت فقط برای توسعه است؛ در محیط production، وجود هر مقدار غیرخالی برای `DEV_OTP_CODE` مانع بالا آمدن API می‌شود. برای تست پیامک واقعی، این متغیر را خالی کن و `KAVENEGAR_API_KEY` معتبر را تنظیم و کانتینر API را مجدداً راه‌اندازی کن.
- پرداخت در حالت sandbox می‌ماند و برای آزمایش کامل به تنظیمات معتبر ارائه‌دهنده نیاز دارد.
- اگر قبلاً `.env` ساخته‌ای، اسکریپت رمزهای موجود را حفظ می‌کند و فقط URLهای تست محلی را به‌روزرسانی می‌کند.
- اجرای واقعی Docker، migration و ورود/پیامک در محیط ساخت این ZIP انجام نشده؛ پس بعد از اجرا، خروجی health endpoint و لاگ‌ها را بررسی کن.
