# گزارش ادغام تغییرات CarMaa

این بسته بر پایه نسخه CarMaa_Smart_Loading_Updated ساخته شده و فایل‌های ارائه‌شده در changed_files_v2.zip در آن ادغام شده‌اند.

## تغییرات ادغام‌شده
- استپر ثبت آگهی با گره‌های آیکون‌دار و خطوط اتصال، برای نمایش واقعی مراحل و Skeleton فرم ثبت آگهی.
- به‌روزرسانی قالب و استایل‌های مربوط به استپر و نسخه‌های کش فایل‌های فرانت‌اند.
- تغییرات ارائه‌شده برای نوار پایین، ریل برندها و کارت‌ها/بخش‌های صفحه اصلی.
- به‌روزرسانی فایل‌های نمایشگاه‌ها و اجزای رندر کوچک.
- اصلاح خواندن حداقل قیمت پیشنهادی فروشنده از منبع فعلی `MARQUE_TRUST` در جریان ویرایش/مدیریت آگهی.
- حفظ اسکریپت‌های اتصال API و بک‌اند در `index.html` آنلاین؛ نسخه آفلاین بدون این اسکریپت‌ها باقی مانده است.

## بررسی
- ساختار ZIP بررسی شده است.
- فایل‌های JavaScript تغییرکرده از نظر syntax بررسی می‌شوند، اما این به‌تنهایی جایگزین اجرای کامل سایت، مرورگر، API یا Docker نیست.
