# قابلیت فهرست بینندگان استوری

## رفتار
- صاحب استوری می‌تواند در صفحه استوری به سمت بالا بکشد یا شمارنده بازدید را لمس کند تا پنل «بینندگان استوری» باز شود.
- پنل فهرست بینندگان واردشده را با نام، نام کاربری، تصویر پروفایل و زمان بازدید نمایش می‌دهد.
- بازدیدهای بدون ورود به حساب فقط به‌صورت شمارنده «بازدیدکنندگان مهمان» نمایش داده می‌شوند؛ شناسه دستگاه یا digest آن به فرانت‌اند ارسال نمی‌شود.
- فقط صاحب همان استوری مجاز به دریافت فهرست است. پاسخ API دارای `Cache-Control: private, no-store` است.
- برای استوری محلی/آفلاین، نام بینندگان قابل بازیابی نیست و رابط این محدودیت را صادقانه نشان می‌دهد.

## فایل‌های تغییرکرده
- `js/27-stories.js`: تشخیص کشیدن رو به بالا، پنل بینندگان، وضعیت بارگذاری/خطا/تلاش مجدد.
- `js/00-api-client.js`: افزودن `social.storyViewers(id)`.
- `backend/src/routes/social.js`: endpoint امن `GET /social/stories/:id/viewers` محدود به صاحب استوری.
- `styles.css`: استایل پنل تیره و راست‌چین.
- `backend/test/story-viewers.test.js`: تست‌های قرارداد و کنترل دسترسی در سطح کد.

## نصب
این اصلاحیه Migration یا تغییر Schema نمی‌خواهد؛ جدول `story_views` از قبل وجود دارد.
پچ را در ریشه پروژه `carmaa` استخراج کنید تا مسیرهای `js/`, `backend/` و `styles.css` جایگزین شوند. قبل از استخراج از این فایل‌ها نسخه پشتیبان بگیرید. سپس تست‌ها را اجرا و سرویس backend و فرانت‌اند را طبق روال معمول پروژه منتشر کنید.

## اعتبارسنجی
- `node --check` برای فایل‌های تغییرکرده موفق.
- `npm --prefix backend run check` موفق.
- `npm --prefix backend test`: 48 تست موفق.
- تست واقعی مرورگر/سرور زنده در این محیط اجرا نشده است.
