بازطراحی صفحه اصلی CarMaa — نسخه editorial / mobile-first

مهم‌ترین تغییرها:
- جست‌وجوی خودرو به ابتدای مسیر کاربر منتقل شد.
- کارت‌های اصلی آگهی‌ها و نمایشگاه‌ها به دو کارت تصویری هم‌وزن و چشمگیر تبدیل شدند.
- میانبرهای پیام‌ها، حساب کاربری و ساخت/مدیریت نمایشگاه در ردیف سه‌تایی منظم قرار گرفتند.
- کارت «ساخت نمایشگاه» دیگر غیرفعال نیست و کاربر را به حساب کاربری هدایت می‌کند.
- ریل آگهی‌های تازه بعد از دسترسی‌های اصلی نمایش داده می‌شود؛ کارت‌های آگهی از استایل بازار خودروی فعلی استفاده می‌کنند.
- سه بنر تکراری با یک بنر محتوایی درباره بررسی جزئیات آگهی جایگزین شد.
- عنوان و معرفی نمایشگاه‌های پیشنهادی شفاف‌تر شد و مرتب‌سازی آن‌ها بر اساس شاخص فعالیت فعلی پروژه حفظ شده است.
- نوار ارزش پیشنهادی شامل جزئیات آگهی، نشان‌های نمایشگاه و گفت‌وگوی مستقیم اضافه شد.
- بخش ثبت آگهی، کنتراست متن، فاصله‌گذاری، حالت‌های hover/focus و ظاهر ریل‌های اسکرولی بازطراحی شدند.
- در موبایل، چیدمان دو کارت بزرگ + سه میانبر کوچک است؛ در نمایشگرهای عریض، صفحه اصلی به چیدمان چندستونه تبدیل می‌شود و ظرف برنامه برای همین صفحه عریض‌تر می‌شود.
- تغییرات در لایه نهایی CSS صفحه اصلی محدود شده‌اند تا تا حد امکان بر صفحات دیگر اثر نگذارند.

فایل‌های اصلی تغییر کرده:
- js/35-home-dashboard.js
- styles.css
- index.html (به‌روزرسانی نسخه فایل‌ها برای جلوگیری از کش قدیمی)

برای اجرا، index.html را باز کنید یا از داخل پوشه پروژه اجرا کنید:
python -m http.server 8000

سپس http://localhost:8000/ را باز کنید. برای مشاهده تغییرات در نسخه میزبانی‌شده، کش مرورگر را به‌روزرسانی کنید.
