# تغییرات اعمال‌شده در سیستم لودینگ CarMaa

## تغییرات
- حذف انتظار اجباری ۱ ثانیه‌ای و Skeleton تمام‌صفحه هنگام هر جابه‌جایی بین صفحات.
- نمایش فوری صفحه مقصد با حفظ اسکرول‌رفتن به بالای صفحه و تاریخچه مرورگر.
- حفظ Skeletonهای اختصاصی برای عملیات واقعاً ناهمگام (مانند بخش‌هایی از پیام‌رسان و پرسش‌وپاسخ)؛ این تغییر آن‌ها را حذف نمی‌کند.
- رعایت `prefers-reduced-motion` برای انواع قدیمی‌تر Skeleton و انیمیشن‌های مرتبط.
- افزودن توضیح در کد درباره دلیل تغییر و محدوده آن.

## دلیل
در نسخه قبلی، تابع `navigateTo` صرف‌نظر از سرعت واقعی صفحه، کل محتوا را با Skeleton جایگزین می‌کرد و پس از یک ثانیه صفحه واقعی را نشان می‌داد. چون رندر بسیاری از صفحات هم‌زمان انجام می‌شود، این انتظار مصنوعی بود و در استفاده مکرر آزار ایجاد می‌کرد.

## بررسی
- فایل‌های JavaScript از نظر syntax بررسی شدند.
- این تغییر به‌تنهایی کش داده یا تغییر API اضافه نمی‌کند؛ فقط انتظار مصنوعی مسیریابی را حذف می‌کند.
- اجرای کامل مرورگر، Docker، API و تست end-to-end در این محیط انجام نشده است.
