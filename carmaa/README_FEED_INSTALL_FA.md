# نصب فید اجتماعی iOS برای CarMaa

این فایل یک **Patch برای پروژهٔ موجود CarMaa** است، نه نسخهٔ کامل پروژه. فایل ZIP را مستقیماً داخل ریشهٔ پروژه استخراج کنید؛ همان پوشه‌ای که `index.html`، پوشهٔ `js/` و پوشهٔ `backend/` داخل آن هستند. اجازهٔ جایگزینی فایل‌های هم‌نام را بدهید.

## قبل از نصب

- از پروژهٔ فعلی یک نسخهٔ پشتیبان بگیرید.
- فایل `backend/.env` و کلیدها/اطلاعات محرمانه را حفظ کنید؛ این Patch هیچ فایل `.env` ندارد.
- فایل‌ها را داخل پوشهٔ موجود `carmaa` استخراج کنید، نه یک پوشه بالاتر یا داخل یک پوشهٔ تودرتوی جدید.

## راه‌اندازی روی سرور با Docker Compose

از ریشهٔ پروژه اجرا کنید:

```bash
docker compose -f docker-compose.prod.yml --env-file backend/.env up -d --build
```

سرویس `migrate`، مهاجرت `021_social_feed.sql` را خودکار اجرا می‌کند و API پس از موفقیت مهاجرت بالا می‌آید. برای مشاهدهٔ وضعیت:

```bash
docker compose -f docker-compose.prod.yml --env-file backend/.env ps
```

در صورت مشاهدهٔ خطا، گزارش سرویس مهاجرت و API را ببینید:

```bash
docker compose -f docker-compose.prod.yml --env-file backend/.env logs --tail=150 migrate api
```

## موارد اضافه‌شده

- مسیر فید در `/feed` و گزینهٔ «فید اجتماعی» در منوی سایت.
- نمایش نوار استوری با استفاده از رندر و رفتار استوری فعلی CarMaa؛ طراحی و رفتار استوری‌های موجود جایگزین نشده است.
- انتشار پست متنی یا پست دارای یک تصویر، با استفاده از سیستم احراز هویت و آپلود فعلی سایت.
- لایک، دیدگاه، اشتراک‌گذاری لینک و حذف پست توسط صاحب آن.
- تب «برای تو» و «دنبال‌شده‌ها» و جست‌وجوی محلی در پست‌های بارگذاری‌شده.
- طراحی تیره با الهام از iOS / Liquid Glass و داک چهارآیتمی در فید: خانه، Chats، دکمهٔ + و حساب کاربری.
- دکمهٔ + فقط در فید، فرم انتشار پست را باز می‌کند؛ در صفحات دیگر به رفتار قبلی «ثبت آگهی» برمی‌گردد.

## محدودیت فعلی

در نسخهٔ فعلی هر پست حداکثر یک تصویر دارد؛ انتشار ویدئو، صفحه‌بندی بی‌نهایت و ابزار مدیریت/گزارش پست‌ها در این Patch پیاده‌سازی نشده‌اند. تب «دنبال‌شده‌ها» نیازمند ورود به حساب است.

## بررسی فنی

بررسی نحوی فایل‌های JavaScript تغییریافته و فایل‌های اصلی Backend انجام شده است. اجرای زنده روی دیتابیس و تست کامل در مرورگر متصل به پروژهٔ واقعی در این محیط انجام نشده؛ بعد از نصب، انتشار یک پست آزمایشی، لایک و ثبت دیدگاه را روی محیط خودتان بررسی کنید.
